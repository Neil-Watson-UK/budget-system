# CMM Budget Excel Dashboard Setup

## Quick Start:
1. Run `setup.bat` (Windows) or `setup.command` (Mac)
2. Open `Budget_Dashboard_Template.xlsx`
3. Update filters in the Dashboard sheet
4. Press **Data → Refresh All** to update

## Features:
- ✅ Live data from database
- ✅ Filter by Region/Status
- ✅ Automatic refresh
- ✅ Pre-formatted dashboard
- ✅ Summary statistics

## Advanced Setup:
For Power Query users:
1. Use `Budget_PowerQuery_Template.xlsx`
2. Modify the query to add custom filters
3. Schedule refreshes via Data → Properties

## Support:
- API URL: https://eposaudioevents.com/budgets/excel_api.php
- Format options: ?format=json, ?format=csv, ?format=xml
- Filter examples: ?region=AMER&status=Approved
